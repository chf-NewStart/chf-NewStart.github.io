Privacy Policy — Read in Phloem

Effective 21 August 2026 · applies to the "Read in Phloem" browser extension, known as "Read in Carrel" before this date. Only the name changed; the practices below are unchanged.

The short version: this extension collects nothing, stores nothing permanently, and sends nothing anywhere. Its only network request is downloading the PDF you explicitly asked for, from the site that hosts it, straight to your own browser.

What the extension does

When you right-click a link and choose “Read link in Phloem” (or click the toolbar button while viewing a PDF), the extension downloads that one PDF and hands it to the Phloem reading app at houfu72.com/reading.html, where it opens for reading. That is the extension’s single purpose.

Data collection

None. The extension does not collect, log, transmit, sell, or share any user data — no browsing history, no analytics, no identifiers, no page content. There is no server: the developer never receives anything from your browser.

Network requests

The extension makes exactly one kind of network request: fetching the PDF you explicitly chose, from the website that hosts it. The request is made with your own browser session, which means a paper you can access through your institution downloads the same way it would if you clicked it normally. No other requests are made.

Storage

The downloaded PDF is held briefly in the extension’s local storage while it is handed to the Phloem tab, then deleted. Nothing else is stored by the extension.

The Phloem web app

Phloem itself is local-first: papers, highlights, and notes are stored in your own browser (IndexedDB and localStorage) on your device. Optional sync features (Google Drive, GitHub) only run if you set them up, and connect your browser directly to your own accounts. Phloem has no analytics and no server of its own.

Changes

If this policy ever changes, the new version will be published at this address with an updated date. Since the extension collects nothing, meaningful changes are unlikely.
