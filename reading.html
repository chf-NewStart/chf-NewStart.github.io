Encrypted GitHub sync

Notes and library metadata become one AES-GCM encrypted file in a private repo. The passphrase and fine-grained token stay in this browser. PDFs remain in your repo’s papers/ folder or on each device.

Screenshot questions

Margin sends extracted screenshot or page text—not the image—to DeepSeek. The API key stays in local storage on this device and is never included in sync.

Library backup
