Sync with Google Drive

One tap connects your own Google Drive. Notes and the library live in a hidden app folder only this app can see — and your PDFs (up to 30 MB each) ride along, so a paper added on one device opens on the others. No tokens, no repos, no passphrase.

Encrypted GitHub sync

Notes and library metadata become one AES-GCM encrypted file in a private repo. The passphrase and fine-grained token stay in this browser. PDFs remain in your repo’s papers/ folder or on each device. If sync ever needs attention, saving here again resets it — or paste a device link from your other device into the address bar and it reconfigures itself.

DeepSeek assistant

Carrel sends extracted screenshot or page text—not the image—to DeepSeek. Technical-term lookup sends the selected phrase and a short nearby excerpt. The API key stays in local storage on this device and is never included in sync.
